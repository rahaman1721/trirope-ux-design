# Trirope Technology — Employee Management System UI/UX Design

## Project Overview

UI/UX design for an **Employee Management System (EMS)** at Trirope Technology. The project focused on designing intuitive admin and employee-facing interfaces for structured workforce management.

## My Role

UI/UX Designer — led the interface design for both admin and employee-facing modules.

## Contributions

- Employee record management interface design
- Admin dashboard and workflow design
- Employee information architecture
- Administrative workflow organization
- Task and attendance visibility improvements
- Role-based interface design (Admin vs Employee views)

## Design Process

### Research & Discovery
- Stakeholder interviews to understand admin and HR workflows
- Identification of pain points in existing manual processes
- User persona development for Admin and Employee roles

### Information Architecture
- Defined data hierarchy for employee records
- Organized navigation structure for admin workflows
- Mapped task flows for key operations (onboarding, attendance, leaves)

### Design
- Wireframes for all primary screens
- High-fidelity UI designs in Figma
- Admin dashboard with key workforce metrics
- Employee self-service interface

### Handoff
- Component specifications and design system documentation
- Developer handoff via Figma

## Tools Used

- Figma
- Miro

## Outcome

Delivered complete UI/UX design covering admin workflows, employee records, and task management interfaces.
